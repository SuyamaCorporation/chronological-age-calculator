# Exact Chronological Age Calculator

A precise age calculation tool that computes the exact time elapsed between a birth date and any target date. Results are broken down into years/months/days as well as total weeks, total days, total hours, total minutes, and total seconds. A birthday countdown section shows a progress bar from the last birthday to the next, with the exact number of days remaining.

## Features

- Input birth date and any target date (defaults to today)
- "Use Today" button instantly sets the target to the current date
- Exact age in years, months, and remaining days (calendar-correct calculation)
- Total duration in weeks, days, hours, minutes, and seconds
- Numbers formatted with thousands separators for readability
- Next birthday countdown with progress bar (% through the current year)
- "Happy Birthday!" message when target date matches birthday
- Input validation with helpful error messages
- Accessible: labeled inputs, error uses role="alert", progressbar has aria values
